# BLACK LION STUDIO Brand Identity

## Overview

BLACK LION STUDIO presents itself as a **high-contrast, editorial, and cinematic digital brand**. The app's identity is built around a restrained monochrome base, a deep blood-red accent, compressed display typography, textured backgrounds, and language that feels deliberate, uncompromising, and avant-garde.

## Color System

| Role | Token / Usage | Value |
| --- | --- | --- |
| Background | `--background` | `hsl(0 0% 100%)` / `#FFFFFF` |
| Foreground | `--foreground` | `hsl(0 0% 3.9%)` / `#0A0A0A` |
| Primary dark | `--primary` | `hsl(0 0% 9%)` / `#171717` |
| Secondary surface | `--secondary` / `--muted` | `hsl(0 0% 96.1%)` / `#F5F5F5` |
| Muted text | `--muted-foreground` | `hsl(0 0% 20%)` / `#333333` |
| Brand accent | `--destructive` and explicit UI usage | `hsl(0 100% 27%)` / `#8A0000` |
| Accent foreground | `--destructive-foreground` | `hsl(0 0% 98%)` / `#FAFAFA` |
| Border | `--border` | `hsl(0 0% 89.8%)` / `#E5E5E5` |

### Color Intent

- **Black / near-black** communicates authority, precision, and weight.
- **White / off-white** creates gallery-style breathing room and sharp contrast.
- **Deep red** is the emotional signature: bold, rare, aggressive, and premium rather than playful.
- **Muted grays** support long-form copy and layered surfaces without diluting the stark visual language.

## Typography

| Role | Current App Usage |
| --- | --- |
| Display / headlines | `"Formula Condensed", sans-serif` (`font-headline`) |
| Body / interface text | `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, Liberation Mono, Courier New, monospace` (`font-body`) |
| Additional loaded font | `Inter` is loaded in `layout.tsx`, but the current Tailwind theme does not map it to a named font utility |

### Type Expression

- Headlines are **condensed, uppercase, oversized, and tightly tracked**, giving the brand an editorial poster feel.
- Paragraphs are often **uppercase, tiny, and widely tracked**, reinforcing precision and a controlled art-direction voice.
- The mono-based body styling makes the interface feel **technical, deliberate, and slightly industrial**.

## Design Philosophy

The product's design language can be described as:

- **Radical intentionality**: every block, label, and interaction feels deliberate.
- **Editorial minimalism**: limited colors, bold typography, and strong hierarchy do the heavy lifting.
- **Cinematic atmosphere**: textured asphalt backgrounds, dark overlays, and hero imagery add mood and drama.
- **Architectural composition**: layouts feel structured and sculptural, especially in the custom bento-style hero.
- **Provocative restraint**: the UI avoids decorative excess, using one strong accent color and assertive copy instead.

## Core Visual Principles

1. **Use contrast as the main branding device.** Favor black, white, and deep red over broad palettes.
2. **Let typography carry identity.** Large condensed headlines should remain the loudest visual element.
3. **Keep surfaces clean but textured.** Plain layouts are supported by subtle background imagery and overlays.
4. **Prefer strong geometry.** Rounded capsules, segmented panels, and cutout compositions should feel intentional and engineered.
5. **Write like the brand looks.** Copy should feel confident, elevated, precise, and a little confrontational.

## Practical Brand Summary

If this brand were expressed in one sentence: **BLACK LION STUDIO is a luxury-forward, high-contrast digital identity that blends brutal precision, cinematic mood, and editorial typography into a bold, narrative-driven experience.**
